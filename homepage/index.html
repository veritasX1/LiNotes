LiNotes

Notizen, Einkaufslisten und Aufgaben für die Familie – so einfach wie Apples Notizen, aber auf dem eigenen Server.

Alles an einem Ort

Auf dem Handy und am Rechner, allein oder gemeinsam – alles gleicht sich in Sekunden ab.

Notizen wie bei Apple

Titel, Überschriften, Checklisten mit Kreisen, Aufzählungen, Fotos, #Tags, angeheftete Notizen und „Zuletzt gelöscht“.

Privat, gemeinsam, geheim

Eigene Ordner nur für dich, gemeinsame Ordner für die Familie – und gesperrte Notizen mit eigenem Passwort.

Einkaufslisten

Einträge landen automatisch in der richtigen Warengruppe. Was einer abhakt, sieht der andere sofort.

Aufgaben-Board

Kanban mit Spalten „Offen“, „In Arbeit“, „Erledigt“, mit Fälligkeit, Zuständigkeit und Farben.

Auch offline

Ohne Netz arbeitest du einfach weiter. Änderungen werden übertragen, sobald wieder Verbindung besteht.

Zwei Geräte, ein Stand

Android-App und Ubuntu-Programm sprechen mit demselben Server und sehen gleich aus.

Auf dem Handy

Gestaltet nach Apples Richtlinien für das iPhone: große Titel, klare Listen, Tab-Leiste unten.

Am Rechner

Deine Notizen bleiben bei dir

Kein Konzern liest mit. Die Daten liegen auf einem eigenen Server zu Hause.

Eigener Server

Alle Notizen, Listen und Bilder liegen auf dem eigenen Server – nicht bei Google, Apple oder Microsoft. Jede Nacht wird auf eine zweite Festplatte gesichert.

Ende-zu-Ende verschlüsselt

Gesperrte Notizen werden schon auf dem Gerät mit deinem Notizen-Passwort verschlüsselt (AES-256). Der Server sieht nur unlesbare Daten.

Getrennte Konten

Jede Person hat ein eigenes Konto. Private Notizen und Bilder sieht nur, wem sie gehören – das prüft der Server bei jedem Zugriff.

Keine Werbung, keine Tracker

Die Apps enthalten keine Werbung, keine Statistik-Dienste und senden nichts an Dritte. Android-Sicherungen in die Google-Cloud sind abgeschaltet.

Sichere Anmeldung

Verbindungen laufen verschlüsselt über HTTPS, Passwörter werden nur als sicherer Hash gespeichert, zu viele Fehlversuche werden gesperrt.

Auch diese Seite

Keine Cookies, kein JavaScript, keine eingebundenen Dienste von Dritten, keine Zugriffsprotokolle.

Android

Für Android 8 und neuer.

Direkt laden

  1. LiNotes-1.0.apk herunterladen (6,7 MB).
  2. Die Datei öffnen. Android fragt einmalig, ob der Browser Apps installieren darf – erlauben.
  3. LiNotes öffnen, „Neues Konto mit Einladungscode“ wählen, den Code eingeben und Benutzername und Passwort festlegen.

Ubuntu

Für Ubuntu 26.04 und andere Systeme mit GTK 4 und libadwaita.

sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 gir1.2-secret-1 python3-cryptography
wget https://linotes.goip.de/download/linotes-ubuntu-1.0.tar.gz
tar xzf linotes-ubuntu-1.0.tar.gz -C ~/.local/share
~/.local/share/linotes/install.sh

Danach steht LiNotes im Anwendungsmenü. Die Anmeldung wird im Schlüsselbund von Ubuntu gespeichert.

Prüfsummen: SHA256SUMS
